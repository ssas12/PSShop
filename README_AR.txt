برنامج إدارة محل البلايستيشن - مشروع أندرويد

يحتوي المشروع على صفحة البرنامج داخل تطبيق Android WebView. لا يحتاج إلى إنترنت أثناء الاستخدام.
الخصائص: أجهزة قابلة للإضافة، الجهازان 1 و5 للمباريات افتراضيًا، شوط أول 6 دقائق وثانٍ 7 دقائق، وقت عادي للأجهزة الأخرى، حساب تكلفة الجلسة، وصوت/اهتزاز عند التنبيه.

طريقة استخراج APK باستخدام GitHub من الهاتف:
1) فك ضغط ملف PSShopAndroid.zip.
2) أنشئ مستودعًا جديدًا في GitHub وارفع جميع ملفات ومجلدات المشروع إليه (بما فيها .github).
3) افتح تبويب Actions في المستودع.
4) اختر Build Android APK ثم Run workflow، أو انتظر اكتمال البناء بعد رفع الملفات.
5) افتح نتيجة التشغيل الناجح، ثم من Artifacts نزّل PSShop-debug-apk.zip.
6) فك ضغطه وستجد app-debug.apk. افتحه على هاتف أندرويد واسمح بالتثبيت من هذا المصدر إذا طلب الهاتف ذلك.

ملاحظات:
- هذا ملف APK تجريبي (debug) للتثبيت الشخصي، وليس إصدارًا منشورًا في متجر Google Play.
- بيانات البرنامج محفوظة محليًا داخل بيانات التطبيق على الهاتف.
- صوت/اهتزاز التنبيه قد يتأثر بإعدادات الصوت وتوفير الطاقة.
